---
title: Storage
description: Listar, enviar, baixar e apagar arquivos do storage de um projeto.
---

## Listar

```http
GET /v1/projects/{projectId}/storage?prefix=imagens/
```

```json
{
  "prefix": "imagens/",
  "folders": ["imagens/produtos"],
  "objects": [
    {
      "id": "obj_...",
      "projectId": "prj_...",
      "key": "imagens/logo.png",
      "name": "logo.png",
      "folder": "imagens",
      "size": 20480,
      "contentType": "image/png",
      "createdAt": "..."
    }
  ],
  "totalBytes": 20480
}
```

`prefix` navega pelas pastas; sem ele, a listagem começa na raiz do projeto.

## Enviar

```http
PUT /v1/projects/{projectId}/storage?key=imagens/logo.png
Content-Type: image/png
```

O corpo é o arquivo. Responde `201` com o objeto criado. Fotos, vídeos e áudios (`Content-Type`
`image/*`, `video/*` ou `audio/*`) vão até **100 MB**; os demais arquivos, até **25 MB**. O total
ocupado conta para o limite de storage do plano (`limit_reached` quando estoura).

## Enviar em partes

Arquivos maiores que 10 MB vão em partes, uma requisição por parte.

**1. Começar.** Os limites de tamanho e de plano são conferidos já aqui, pelo `size` informado.

```http
POST /v1/projects/{projectId}/storage/uploads
Content-Type: application/json

{ "key": "videos/intro.mp4", "contentType": "video/mp4", "size": 26214400 }
```

```json
{ "uploadId": "...", "key": "videos/intro.mp4", "partBytes": 10485760 }
```

**2. Enviar cada parte**, numeradas a partir de `1`. Todas têm exatamente `partBytes`, menos a
última, que pode ser menor.

```http
PUT /v1/projects/{projectId}/storage/uploads/parts?key=videos/intro.mp4&uploadId=...&partNumber=1
Content-Type: application/octet-stream
```

```json
{ "partNumber": 1, "etag": "..." }
```

**3. Concluir** com as respostas de todas as partes. Responde `201` com o objeto, como no envio
direto. O tamanho real é conferido de novo; se passar do limite, o arquivo é descartado.

```http
POST /v1/projects/{projectId}/storage/uploads/complete
Content-Type: application/json

{ "key": "videos/intro.mp4", "uploadId": "...", "parts": [{ "partNumber": 1, "etag": "..." }] }
```

Para desistir no meio, `POST /v1/projects/{projectId}/storage/uploads/abort` com `key` e
`uploadId` (responde `204`). Um envio que não é concluído some sozinho depois de alguns dias.

## Baixar

```http
GET /v1/projects/{projectId}/storage/{objectId}/content
```

Devolve o arquivo com o `content-type` original e `content-disposition: attachment`.

Para uso no site, o arquivo também é servido publicamente pelo endereço do projeto:

```txt
https://meu-site.paranhos.cloud/_storage/imagens/logo.png
```

## Apagar

```http
DELETE /v1/projects/{projectId}/storage/{objectId}
```

Responde `204`. A remoção é imediata e não tem desfazer.
