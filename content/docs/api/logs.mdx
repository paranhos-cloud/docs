## Listar

```http
GET /v1/projects/{projectId}/logs?level=error&search=/checkout
```

```json
[
  {
    "id": "128",
    "timestamp": "2026-09-20T14:35:12.000Z",
    "level": "info",
    "message": "GET /sobre 200 12ms ray=8f3c1b2a4d5e6f70"
  }
]
```

| Parâmetro | Valores | Padrão |
| --- | --- | --- |
| `level` | `all`, `debug`, `info`, `warn`, `error` | `all` |
| `search` | trecho da mensagem, até 200 caracteres | vazio |

São devolvidas até **500 linhas**, das mais antigas para as mais recentes dentro desse recorte. O
nível vem do código HTTP: 2xx e 3xx são `info`, 4xx é `warn` e 5xx é `error`.

Os registros ficam guardados por **7 dias**. O log de build não está aqui — ele fica na execução do
GitHub Actions, cujo endereço vem em `buildUrl` no [deploy](/api/deploys).
